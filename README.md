# HY FI 채권운용 실습

금융인공지능실무 기말 시연용 웹 앱이다. 삼성전기 별도 감사보고서의 만기표에서 1년 내 지급액을 확인하고, 가상 장외호가에서 거래 방향과 금리를 읽어 볼 수 있다.

## 실행

GitHub에서 **Code → Download ZIP**을 선택해 압축을 푼 뒤 **index.html**을 브라우저에서 연다. 폴더 안의 JS·CSS 파일은 같은 위치에 둔다. 시연에는 Python 설치, API 키, 인터넷 연결이 필요하지 않다. 원문 PDF 링크를 열거나 모델 색인을 다시 만들 때 인터넷을 사용한다.

1. **공시 분석**에서 2025.12.31과 단기차입금을 선택한다. 답 옆의 두 만기 구간과 아래 표의 강조된 행을 비교한다. **공시 원문 열기**를 누르면 발행사 PDF의 104쪽으로 이동한다.
2. 리스부채로 바꾸고 보고기간을 전환한다. 3개월 이내와 그 이후 1년 이내의 지급액을 더하는 과정을 비교한다. 담보부차입금을 선택하면 독립된 근거 행이 없어 **원문 확인 필요**로 표시된다.
3. **장외호가**에서 기준금리 정수부 3과 `가상A 79/795사자`를 입력한다. 구성 금리는 3.790%와 3.795%, 대표 금리는 3.792%, 방향은 매수다. 0.5bp 간격의 두 금리를 정수로 평균한 뒤 소수 셋째 자리까지 절사한다. 단일 금리와 방향 미표시도 처리한다.

## 긴 공시의 길이와 처리 비용

전체 PDF를 로컬에서 페이지별로 읽고, 유동성위험 주석의 제목을 찾아 당기말·전기말 표를 분리한다. 같은 토크나이저로 원문 122쪽에서 **45,849토큰**을 셌다. 각 표의 합계 행은 검산에 쓰고, 나머지 4행씩 총 8행을 색인한다. 각 행에 회사, 기준일, 단위, 열 이름과 금액을 함께 담아 문장을 나눌 때 표의 의미를 잃지 않게 했다. [원문 PDF 104쪽](https://www.samsungsem.com/resources/file/kr/ir/archive/2025_Separate_Audit_Report.pdf#page=104)

| 측정 항목 | 이번 실행 결과 | 코드에서 정한 한도 |
| --- | ---: | --- |
| PDF 전체 텍스트 | 45,849토큰 | 페이지별 토큰 수 합산. 특수 토큰 제외 |
| 근거 8행의 실제 인코더 입력 합계 | 535토큰 | 색인 1회당 1,024토큰 |
| 가장 긴 근거 행 | 75토큰 | 입력 한 건당 128토큰 |
| 질문 4개의 개별 입력 | 17 / 15 / 19 / 21토큰 | 질문마다 128토큰 |
| 브라우저에서 같은 질문을 다시 선택 | 모델 호출 0회 | 저장된 384차원 벡터 재사용 |

근거 색인 입력은 원문 토큰 수의 약 **1.17%**다. 행·질문의 입력량은 실제 ONNX 인코더에 넣은 특수 토큰을 포함한다. 최초 색인과 질문 네 개를 만드는 데 사용한 입력은 합계 **607토큰**이다. 원문 토큰 계수와 표 추출은 전체 페이지를 읽으므로 이 비율은 모델에 들어간 텍스트의 양을 설명한다. 실행 시간이나 금액 절감률은 별도로 측정해야 한다.

**길이 초과 처리.** 인코더는 행 또는 질문이 128토큰을 넘으면 해당 입력을 거부한다. 색인 전체의 상한을 넘겨도 작업을 중지한다. 단위나 만기 구간이 다른 표, 행·열 합계가 공시의 천원 단위 반올림 허용치인 1을 넘게 어긋나는 표도 확인 대상으로 남긴다. 결과 파일은 전체 검증이 끝난 뒤 교체한다.

**검색과 계산.** 양자화한 다국어 MiniLM Transformer로 각 행과 질문을 인코딩하고, 토큰 벡터를 평균한 뒤 정규화한다. 브라우저는 선택한 연도에 속한 행을 질문 벡터와의 코사인 유사도순으로 정렬한다. 해당 질문에 지정된 회계 항목과 일치하는 행이 하나일 때 첫 두 열을 더한다. 숫자가 비슷한 여러 행에서는 유사도 1위가 틀릴 수 있다. **근거 행을 선택한 과정**을 열면 순위와 실제로 사용한 행을 비교할 수 있다. [모델 설명](https://huggingface.co/sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2) · [ONNX 가중치](https://huggingface.co/Xenova/paraphrase-multilingual-MiniLM-L12-v2)

## 원문 대조 결과

삼성전기 제53기 별도 감사보고서 주석 26-3의 할인 전 계약상 현금흐름이다. 숫자는 천원 단위이며 연결 기준 수치와 구별한다. 원표의 대시는 합산 시 0으로 처리한다.

| 1년 이내 지급 항목 | 2025.12.31 | 2024.12.31 |
| --- | ---: | ---: |
| 단기차입금 | 1,213,903,625 | 708,294,579 |
| 리스부채 | 2,258,010 | 2,157,842 |
| 매입채무및기타채무 | 875,900,619 | 744,286,650 |
| 담보부차입금만 별도 조회 | 원문 확인 필요 | 원문 확인 필요 |

예를 들어 2025년 말 리스부채의 1년 이내 지급액은 604,598 + 1,653,412 = **2,258,010천원**이다. 마지막 합계 열의 8,004,137천원에는 1년 이후 지급분도 포함된다. [감사보고서 원표](https://www.samsungsem.com/resources/file/kr/ir/archive/2025_Separate_Audit_Report.pdf#page=104)

## 소스에서 재현

웹 화면은 저장소에 포함된 색인으로 바로 작동한다. 원천 PDF 추출, 토큰 계수, 실제 모델 추론까지 다시 수행하려면 64비트 Python 3.12 환경에서 아래 명령을 실행한다. Windows PowerShell 기준이다.

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe build_index.py
```

macOS·Linux에서는 `python3.12 -m venv .venv`로 환경을 만들고 위 두 명령의 Python 경로를 `.venv/bin/python`으로 바꾼다. 첫 실행은 삼성전기 PDF와 고정 버전 모델·토크나이저 약 136MB를 내려받는다. 출처 파일의 SHA-256을 검사한 뒤 `.cache/`에 재사용하고, 생성한 `evidence.js`를 교체한다. 모든 추론은 CPU에서 수행한다.

Node.js가 있는 환경에서 브라우저와 같은 계산 코드를 아래 명령으로 검증할 수 있다.

```sh
node verify.cjs
```

두 기간의 정답 8개, 출처 페이지, 입력 상한, 호가 방향·절사·미지원 입력을 확인한다. 시연 범위는 이 보고서 양식과 미리 정의한 네 질문이다. 다른 회사의 공시를 추가하려면 기간·단위·열 구조와 검증용 정답을 먼저 등록해야 한다.

| 파일 | 역할 |
| --- | --- |
| `build_index.py` | PDF 추출, 표 검증, 토큰 상한 적용, ONNX 임베딩 생성 |
| `evidence.js` | 출처·측정치·예제 표의 수치와 미리 계산한 벡터 |
| `finance.js` | 근거 검색·금액 계산, 가상 장외호가 파싱 |
| `index.html`, `app.js`, `style.css` | 두 시연 화면 |
| `verify.cjs` | 모델 입력량과 금융 계산의 재현 검사 |
